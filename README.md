# אפליקציית מתכונים: קוד התחלה לזוגות

דרישות: Node 22.22 ומעלה (בדיקה: `node -v`).

## הרצה

```
npm install
npm run dev
```

## המשימה

- תלמידה א׳: ענף `feature/recipes-list`, קובץ `src/pages/RecipesList.jsx`, נתיב `recipes`.
  שימוש ב־`Link` וב־`useSearchParams`.
- תלמידה ב׳: ענף `feature/recipe-details`, קובץ `src/pages/RecipeDetails.jsx`, נתיב `recipes/:id`.
  שימוש ב־`Link` וב־`useParams`.

ההוראות המלאות נמצאות בדף התרגיל.

## כללים

1. לא עובדים ישירות על `main`
2. לכל משימה ענף משלה
3. חוזרים ל־`main` רק דרך Pull Request
4. שותפה אחת לפחות עושה Review לפני Merge

## API

- רשימה: https://dummyjson.com/recipes
- מתכון בודד: https://dummyjson.com/recipes/1
